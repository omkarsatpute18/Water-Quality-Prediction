# 💧 Water Quality Prediction

## 📌 Project Overview

Water quality is an important factor in determining whether water is suitable for consumption. This project uses Machine Learning to predict whether a given water sample is **Potable** or **Not Potable** based on different water quality parameters.

The project implements an end-to-end Machine Learning workflow, starting from data preprocessing and model training to evaluation and deployment as a web application.
